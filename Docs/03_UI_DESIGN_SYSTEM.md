# PixelFind — UI Design System

## Design Principle
Important : Use Shadcn UI components and styling. 
PixelFind should feel like a serious productivity utility,
not an AI marketing website.

Reference direction:

Apple Files
Linear
Modern desktop productivity software

---

## Colors

Background: #F7F7F5
Surface: #FFFFFF
Primary text: #171717
Secondary text: #737373
Border: #E7E7E4
Accent: #2F5D50
Accent light: #E8F0ED

---

## Typography

Use a clean modern sans-serif.

Prioritize:

- readability
- hierarchy
- compact UI
- clear labels

---

## Components

- Sidebar
- Search bar
- Screenshot card
- Tag
- Filter chip
- Progress bar
- Empty state
- Modal
- Detail panel
- Toast

---

## Screenshot Grid

Desktop:

4 columns when space allows.

Tablet:

3 columns.

Small screens:

2 columns.

---

## Motion

Use subtle motion only.

Examples:

- card hover
- page transitions
- indexing progress
- modal transitions

Avoid decorative animations.

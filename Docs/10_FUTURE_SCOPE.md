# Future Scope

The following features are intentionally not required
for the Review 2 prototype.

## Semantic Retrieval

Use browser-based embeddings to improve context matching.

## Visual Similarity

Find screenshots that look visually similar.

## Voice Search

Allow users to speak queries.

## Multimodal Understanding

Analyze screenshots beyond visible OCR text.

## Sensitive Information Detection

Detect possible:

- API keys
- passwords
- secrets

## Feedback Ranking

Allow users to indicate whether a result was useful.

## Session Grouping

Group screenshots captured during the same activity/project.
